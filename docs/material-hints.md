# Material hints

Which Pokémon have surfaces that need more than the usual material, judged from what each
creature is (official art, Pokédex text, wikis), not from the sprites. Every sprite still gets a
material for each surface (see [materials.md](materials.md)); this list only names the ones that are
easy to get wrong.

| Key | Setting | For |
| --- | --- | --- |
| Glow | glow on those pixels (and an emission track if it flickers) | fire, lava, glowing eyes and orbs, electricity, bioluminescence |
| Clear | body 1 | ice, glass, crystal, water, jelly, clear wings |
| Translucent | body 0.5 | thin membranes, petals and wings that light passes through |
| Faded | the pixels drawn partly transparent | ghost wisps, gas, smoke, mist |
| Metal | body −1, finish 1 | real metal: Steel hides, armor, blades, magnets, bolts |
| Polished | finish as given | wet or slimy skin, polished shells, gems, pearls, ceramic |
| Fuzzy, Grainy | finish −1 or −0.6 | fluff, cotton and cloud; sand and dust |

Numbers are starting points on the two dials (finish −1 fuzzy to 1 polished; body −1 metal to 1
clear). *Shiny* notes mean the shiny palette changes a glow color, which must be checked separately.
